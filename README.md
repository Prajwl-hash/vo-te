# 🎙️ Voice-to-Notes

A backend-focused application that converts voice recordings into structured, searchable notes.

The project is being built with **FastAPI, PostgreSQL, SQLAlchemy, Supabase, and Python**, with speech-to-text and AI-powered note processing planned for the next phase.

---

## 🚀 Project Vision

The goal is to build a system where a user can:

1. Record or upload a voice note
2. Convert speech into text
3. Process the transcript using AI
4. Generate a clean and structured note
5. Store and retrieve notes from a database
